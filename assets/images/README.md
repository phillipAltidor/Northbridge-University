# Campus Image

`northbridge-campus.png` was created with the built-in image-generation tool
for this fictional university. It is not a photograph of a real Northbridge
campus. No external image service is required at runtime.

The welcome and login pages use this image. The university mark remains the
original gold N inside a circle, rendered by the shared `.seal` CSS class.

Generation prompt:

> Use case: photorealistic-natural. Asset: wide campus photograph for fictional Northbridge University welcome website. Crisp architectural details, natural balanced light, clear blue sky. Wide horizontal composition with building visible in center and right, uncluttered darker green foliage at lower left for white website title overlay. No lettering, logos, signage or watermark.
